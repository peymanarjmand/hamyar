# حساب‌یار تعمیرگاه

اپلیکیشن اندرویدی کاملاً آفلاین برای مدیریت پرسنل، همکاری و غیبت، انعام مشتری، فروش ضایعات، امانت پول مشترک، انتقال امانت، تسویه و بستن سال مالی شمسی.

## ویژگی‌های اصلی

- رابط کاملاً فارسی، راست‌به‌چپ و Material 3
- تقویم شمسی داخلی؛ ذخیره تاریخ‌ها به‌شکل مستقل و دقیق
- ثبت چند دوره همکاری و غیبت موقت برای هر شخص
- قانون غیبت تأییدشده: روزهای ۱ تا ۱۴ سهم دارد و از روز ۱۵ سهم ندارد
- تقسیم مساوی و نگهداری شفاف باقیمانده تقسیم برای رویداد بعدی
- جداسازی «سهم»، «امانت پول گروه» و «پرداخت تسویه»
- انتقال جزئی امانت بین افراد و حساب‌های نقد/کارت با ردیابی FIFO تا درآمد اولیه
- نمایش بدهکار/بستانکار و پیشنهاد پرداخت‌های کمینه
- ثبت تهاتر داخلی و پرداخت واقعی جزئی یا کامل
- شماره کارت کامل، اعتبارسنجی شتاب، رمزگذاری محلی و نمایش ماسک‌شده
- فایل پشتیبان کامل و رمزدار با SAF و کنترل صحت SHA-256
- بستن نهایی سال شمسی پس از تسویه و پشتیبان نهایی؛ تاریخچه سال بسته فقط‌خواندنی است
- بدون مجوز اینترنت، Firebase، تبلیغ یا حساب کاربری

## فناوری

Kotlin 2.3، Jetpack Compose، Material 3، Room، DataStore، Coroutines/Flow، Android Keystore و Storage Access Framework.

## ساخت

```powershell
.\gradlew.bat test lint assembleRelease
```

APK خروجی Gradle در مسیر زیر ساخته می‌شود:

`app/build/outputs/apk/release/app-release.apk`

حداقل Android 8 (API 26)، target Android 16 (API 36) و معماری universal است.
