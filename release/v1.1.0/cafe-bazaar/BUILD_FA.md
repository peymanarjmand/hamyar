## قرارداد آپدیت‌های بعدی

برای اینکه نسخه‌های بعدی بدون حذف برنامه روی نسخه بازار نصب شوند، هر سه مورد زیر باید حفظ شوند:

1. شناسه بسته همیشه `com.hesabyar.garage` باقی بماند.
2. هر نسخه جدید `versionCode` بزرگ‌تر از `3` داشته باشد.
3. همه نسخه‌ها فقط با کلید `.release-signing/hesabyar-release.jks` و نام مستعار `hesabyar` امضا شوند.

کلید و فایل اعتبارنامه داخل `.release-signing/` همین پروژه هستند و عمداً توسط Git نادیده گرفته می‌شوند. فایل اعتبارنامه با Windows DPAPI رمزگذاری شده و فقط با حساب ویندوز فعلی قابل بازیابی است. برای انتقال رمز به یک مدیر رمز امن، دستور زیر را فقط روی همین رایانه اجرا کنید و خروجی آن را در چت، Git یا اسناد پروژه قرار ندهید:

```powershell
(Import-Clixml -LiteralPath '.\.release-signing\hesabyar-release-credential.clixml').GetNetworkCredential().Password
```

پیش از انتشار عمومی، از فایل کلید و رمز آن یک نسخه پشتیبان رمزگذاری‌شده و خارج از رایانه تهیه کنید. گم‌شدن کلید یا رمز بعد از اولین انتشار، امکان ارائه آپدیت سازگار را از بین می‌برد.
