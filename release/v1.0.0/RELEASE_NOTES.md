# HesabYar Garage 1.0.0

The first public release of the offline-first Persian workshop accounting application.

## Highlights

- Persian RTL interface and Solar Hijri calendar
- Personnel, employment, and absence management
- Equal tip and scrap-income sharing with the 14-day absence rule
- Separate entitlement and shared-money custody ledgers
- Partial cash/card transfers with source-level traceability
- Debtor/creditor balances and auditable settlements
- Encrypted card storage and password-protected portable backups
- Final year close with read-only historical years

## Compatibility

- Android 8.0 (API 26) and newer
- Universal APK: arm64-v8a, armeabi-v7a, x86, x86_64
- Package: `com.hesabyar.garage`

## Integrity

Verify the downloaded APK using the SHA-256 checksum asset included with this release.
