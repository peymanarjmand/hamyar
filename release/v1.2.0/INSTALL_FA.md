# نصب و ارتقا به حساب‌یار ۱.۲.۰

پیش از هر به‌روزرسانی از داخل برنامه یک فایل پشتیبان رمزدار بسازید و رمز آن را در محل امن نگه دارید.

## ارتقا از نسخه عمومی ۱.۱.۰

اگر نسخه ۱.۱.۰ کافه‌بازار یا APK عمومی با گواهی دائمی روی گوشی نصب است، APK عمومی ۱.۲.۰ را مستقیم باز کنید و «به‌روزرسانی» را بزنید. شناسه بسته، دیتابیس Room و امضای دائمی ثابت‌اند؛ Android باید اطلاعات برنامه را حفظ کند.

## انتقال از نسخه‌های محلی ۱.۰.۰ یا ۱.۰.۱

APKهای محلی قدیمی با گواهی Android Debug امضا شده‌اند و نسخه عمومی دائمی روی آن‌ها نصب درجا نمی‌شود:

1. در نسخه قدیمی یک پشتیبان رمزدار بسازید.
2. فایل و رمز را خارج از پوشه خصوصی برنامه نگه دارید.
3. نسخه Debug قدیمی را حذف کنید.
4. APK عمومی ۱.۲.۰ را نصب کنید.
5. از «بیشتر ← بازیابی کامل اطلاعات» همان فایل را بازیابی کنید.

## مشخصات

- بسته: `com.hesabyar.garage`
- نسخه: `1.2.0` / کد نسخه `4`
- حداقل Android: 8
- target SDK: 36
- معماری APK: universal شامل `arm64-v8a` برای Samsung A52s 5G
- مجوز اینترنت: ندارد

فقط APKی را نصب کنید که امضا و SHA-256 آن با `RELEASE_RECORD.md` و فایل checksum همان کانال انتشار تطبیق داشته باشد.
