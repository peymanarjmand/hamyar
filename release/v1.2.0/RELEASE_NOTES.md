# HesabYar Garage 1.2.0

این نسخه مدیریت پرسنل و غیبت را کامل‌تر می‌کند و قانون تعلق سهم در غیبت را از یک مقدار ثابت به تنظیم قابل‌کنترل تعمیرگاه تبدیل می‌کند.

## امکانات جدید

- ویرایش نام، شماره تماس، نقش و یادداشت هر پرسنل
- ویرایش تاریخ شروع و پایان دوره‌های همکاری با کنترل هم‌پوشانی و اعتبار غیبت‌های موجود
- ویرایش غیبت موقت و ثبت مستقیم روز بازگشت برای غیبت‌های باز
- نمایش وضعیت «سهم دارد/سهم ندارد» هر غیبت طبق قانون جاری
- تنظیم ۰ تا ۳۶۵ روز غیبت مشمول سهم از بخش «بیشتر»؛ پیش‌فرض ۱۴ روز
- کارت توسعه‌دهنده شامل پیمان ارجمند، ایمیل و لینک مستقیم بله/تلگرام

## سازگاری حسابداری و پشتیبان

- تغییر مشخصات، غیبت یا قانون جاری، سهم، طلب، امانت، FIFO، باقیمانده و Snapshot درآمدهای قبلی را تغییر نمی‌دهد.
- تنظیم جدید فقط در پیش‌نمایش و درآمدهایی که بعد از تغییر ثبت می‌شوند استفاده می‌شود.
- Backup schema 3 قانون غیبت را نگه می‌دارد و Backupهای schema 1 و 2 را با مقدار پیش‌فرض ۱۴ روز بازیابی می‌کند.
- Room همچنان نسخه ۲ است و داده نسخه ۱.۱.۰ بدون migration جدید حفظ می‌شود.

## انتشار و نصب

- نسخه برنامه: `1.2.0` / کد نسخه: `4`
- شناسه بسته: `com.hesabyar.garage`
- حداقل Android: 8 / API 26
- compile/target SDK: 36
- مجوز اینترنت: ندارد

APK عمومی باید با همان گواهی دائمی نسخه ۱.۱.۰ امضا شود. جزئیات ارتقا از نسخه‌های عمومی و محلی Debug-signed در `INSTALL_FA.md` آمده است.
