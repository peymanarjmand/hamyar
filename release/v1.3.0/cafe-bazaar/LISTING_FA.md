# متن تغییرات کافه‌بازار — نسخه ۱.۳.۰

- امکان روشن یا خاموش‌کردن سهم هر پرسنل از انعام و فروش ضایعات
- نمایش ساده‌تر سهم کل، سهم تسویه‌شده، پول مشترک نزد فرد و مبلغ نهایی دریافت یا پرداخت

- بهبود عبارت‌های مالی برای جلوگیری از اشتباه بین سهم شخصی و پول مشترک گروه
