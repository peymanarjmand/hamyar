# نصب و ارتقا به حساب‌یار ۱.۳.۰

پیش از هر به‌روزرسانی از داخل برنامه یک فایل پشتیبان رمزدار بسازید و رمز آن را در محل امن نگه دارید.

## ارتقا از نسخه عمومی با امضای دائمی

اگر نسخه ۱.۱.۰ یا ۱.۲.۰ با شناسه `com.hesabyar.garage` و گواهی دائمی روی گوشی نصب است، APK عمومی ۱.۳.۰ را مستقیم باز کنید و «به‌روزرسانی» را بزنید. migration غیرتخریبی Room اطلاعات فعلی را حفظ می‌کند و پرسنل موجود به‌صورت پیش‌فرض مشمول سهم ثبت‌های جدید باقی می‌مانند.

نسخه‌های محلی قدیمی که با Android Debug امضا شده‌اند باید پس از ساخت پشتیبان حذف شوند و اطلاعاتشان بعد از نصب نسخه عمومی بازیابی شود.

## مشخصات

- بسته: `com.hesabyar.garage`
- نسخه: `1.3.0` / کد نسخه `5`
- Room: نسخه `3`
- Backup: schema `4` با پذیرش `1..4`
- حداقل Android: 8 / API 26
- target SDK: 36
- مجوز اینترنت: ندارد

فقط APKی را نصب کنید که امضا و SHA-256 آن با `RELEASE_RECORD.md` و checksum همان کانال انتشار مطابقت داشته باشد. پیش از انتشار عمومی، نتیجه Play Protect فایل دقیق باید در `PLAY_PROTECT_APPROVAL.env` به حالت تأییدشده برسد.
