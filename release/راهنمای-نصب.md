# نصب حساب‌یار تعمیرگاه

فایل `HesabYar-Garage-v1.0.0.apk` نسخه نهایی آفلاین و قابل نصب است.

1. فایل را به Samsung A52s 5G منتقل کنید.
2. روی فایل بزنید.
3. اگر Android درخواست کرد، برای برنامه فایل‌منیجر یا مرورگر گزینه «اجازه نصب برنامه‌های ناشناس» را فعال کنید.
4. «نصب» را بزنید و راه‌اندازی اولیه را انجام دهید.

مشخصات:

- شناسه: `com.hesabyar.garage`
- نسخه: `1.0.0`
- حداقل Android: 8
- target: Android 16
- معماری: universal شامل arm64-v8a گوشی A52s
- مجوز اینترنت: ندارد
- امضا: APK Signature Scheme v2؛ مناسب نصب مستقیم شخصی

قبل از تعویض یا ریست گوشی حتماً از داخل برنامه فایل پشتیبان رمزدار بسازید و رمز را در جای امن نگه دارید.
